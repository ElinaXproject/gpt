# Szybki start — warsztat asystenta

## Gdzie są pliki
- GitHub: https://github.com/ElinaXproject/gpt — wersjonowana dokumentacja.
- ChatGPT Library: /Assistant_Workbench/ — magazyn plików.
- Notion: GPT Workbench — centrum operacyjne — wiedza, decyzje i zadania.

## Jak wznowić pracę
1. Odczytaj WORKBENCH_STATE.md oraz INTEGRATION_STATUS.md.
2. Odczytaj dokument projektu, listę zadań i decyzje, jeśli istnieją.
3. Sprawdź narzędzia i uprawnienia w bieżącej rozmowie.
4. Wykonuj pracę etapami; nie pytaj ponownie o znane dane.
5. Po istotnej zmianie aktualizuj stan i listę zadań.
6. Zweryfikuj zapis przez ponowny odczyt.

## Oznaczenia
PLAN — zaplanowane; DOING — w trakcie; DONE — wykonane, bez niezależnej weryfikacji; VERIFIED — wykonane i sprawdzone; BLOCKED — zablokowane z podanym powodem.

## Ograniczenia
Dostęp zależy od bieżących narzędzi i uprawnień. Dropbox upload pozostaje niepotwierdzony. Google Drive jest wyłączony przez administratora.
