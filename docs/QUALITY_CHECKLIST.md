# Kontrola jakości

## Zrozumienie
- [ ] Cel i kryteria akceptacji są jasne.
- [ ] Wykorzystano dostępny kontekst.
- [ ] Fakty, założenia i niewiadome są rozdzielone.

## Wykonanie
- [ ] Użyto właściwych narzędzi i aktualnych schematów.
- [ ] Nie wykonano nieautoryzowanych działań zewnętrznych.
- [ ] Zachowano oryginały i możliwość wycofania zmian.

## Wynik
- [ ] Każdy wymóg został sprawdzony.
- [ ] Wynik nie zawiera niezweryfikowanych twierdzeń.
- [ ] Ograniczenia są jawne.
- [ ] Stan projektu i następny krok zostały zapisane.
