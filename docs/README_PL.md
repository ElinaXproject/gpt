# Warsztat pracy asystenta — zestaw startowy

Ten pakiet porządkuje pracę nad większymi zadaniami i projektami. Zawiera procedury, szablony, testy oraz opis magazynu plików i integracji.

## Gdzie co przechowywać
- **Notion:** centrum wiedzy, decyzji, dokumentacji operacyjnej i zadań. Główny indeks: GPT Workbench — centrum operacyjne.
- **ChatGPT Library:** magazyn plików roboczych, katalog /Assistant_Workbench/.
- **GitHub:** repozytorium ElinaXproject/gpt; zapis i odczyt zostały przetestowane, README.md utworzono i odczytano kontrolnie.
- **Dropbox:** odczyt/listowanie działa; upload pozostaje niepotwierdzony.

## Zasady
1. Przed wznowieniem projektu odczytaj stan, zadania i decyzje.
2. Wykorzystuj znany kontekst; nie pytaj ponownie o znane informacje.
3. Zachowuj oryginały i weryfikuj każdą zmianę.
4. Oznaczaj wyniki jako PLAN, DOING, DONE, VERIFIED albo BLOCKED.
5. Nie zapisuj haseł, tokenów, kluczy API ani danych płatniczych.

## Ograniczenia
Pakiet nie zmienia modelu AI, nie daje nieograniczonego dostępu do kont ani nie zapewnia samodzielnej pracy w tle. Nie deklaruj synchronizacji między usługami bez potwierdzonego zapisu.
